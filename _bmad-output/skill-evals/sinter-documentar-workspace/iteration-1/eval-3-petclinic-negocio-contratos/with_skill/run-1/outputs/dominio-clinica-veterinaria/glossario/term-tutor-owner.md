# Tutor (Owner)
Pessoa responsável por um ou mais pets cadastrados na clínica. No código é chamado de `Owner` (nome, sobrenome, endereço, cidade, telefone e a lista de pets).

Não confundir com: **Equipe clínica** (quem opera o sistema/atende, não é dono de pet) — o código não distingue esses dois papéis de usuário.
