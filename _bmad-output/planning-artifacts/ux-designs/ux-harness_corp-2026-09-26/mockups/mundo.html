O mundo do domínio

Pagamentos como um mundo: cada subdomínio é uma constelação na superfície, cada sistema é uma estrela (o tamanho é o número de integrações). Arraste para girar, clique numa estrela para selecionar, clique num subdomínio à esquerda para voar até ele. No nível Empresa, cada domínio seria um mundo diferente.
